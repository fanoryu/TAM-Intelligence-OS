# Delta Progress Reports (DPR)

Milestone-progress records for **Milestone Delta** — each DPR records the implementation status and
direction at a point in the milestone. A DPR is factual and forward-pointing; it authorizes no work
(a Sprint Assignment does that). DPRs are **superseded**, never rewritten (`CLAUDE.md` §14.4, §16.2).
